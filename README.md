# Cyberpunk inspired theme for btop

Just that, a Cyberpunk 2077 inspired theme for btop

## Installation
#### Step 1
Copy the file 'cyberpunk.theme' to one of the default folders,  

either *(requires root)*: 
```
/usr/[local/]share/btop/themes
```
or *(doesn't require root)*:
```
~/.config/btop/themes
```
#### Step 2
Choose the theme from the config menu

#### Step 3
Enjoy
