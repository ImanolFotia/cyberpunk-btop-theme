# Cyberpunk inspired theme for btop

Just that, a Cyberpunk 2077 inspired theme for btop

## Installation
1. 
Copy the file 'cyberpunk.theme' to the default folders:
Either:
```
/usr/[local/]share/btop/themes
```
or 
```
~/.config/btop/themes
```
2. 
Choose the theme from the config menu

3. 
Enjoy
